# CanvasCast

在桌面浏览器里制作白板讲解、组织幻灯片并录制视频。CanvasCast 将可编辑的绘图、文字和图片，与录制背景、可选摄像头小窗、独立麦克风选择和提词器放在同一个工作区中。

这是一个面向个人学习和作品集展示的项目，适合短课程、算法与技术讲解、可视化笔记，以及项目或产品流程演示。

## 制作与录制流程

1. 使用桌面浏览器打开在线演示，或按照下方说明在本地运行。
2. 用画笔、矩形、椭圆、箭头、直线、文字和本地图片制作讲解内容。可以选择和变换对象、使用对象级橡皮，并撤销或重做编辑。
3. 用幻灯片组织讲解，通过缩略图切换页面，在录制前复制、重命名、删除或拖拽排序。
4. 打开录制设置，选择画布比例、颜色、样式、边距和圆角，以及内置背景图或随机背景。
5. 按需开启摄像头小窗，独立选择麦克风，并将脚本粘贴到浮动提词器中，调整滚动速度和透明度。
6. 进入录制准备，开始录制并按页讲解。支持暂停、继续和切换幻灯片；演示时也可以用左右方向键翻页。
7. 停止录制后下载视频。建议先试录一小段，确认画面、声音和浏览器支持的格式。

| 工作环节 | 已有控制 |
| --- | --- |
| 白板编辑 | 平移与缩放、SVG 自由画笔、图形、文字和图片，以及单对象和多对象变换 |
| 幻灯片组织 | 缩略图、复制、删除、重命名和拖拽排序 |
| 录制构图 | 16:9、4:3、3:4、9:16、1:1 比例；无纹理、横线、网格或格点画布；背景图和光标效果 |
| 演示辅助 | 可选摄像头小窗与麦克风输入、浮动提词器、暂停/继续和幻灯片切换 |
| 视频输出 | 按浏览器支持的录制类型生成并下载 MP4 或 WebM |

## 本地运行

需要 Node.js 和 npm。Node.js 应满足锁文件中 Vite 的要求：`^20.19.0 || >=22.12.0`。

```bash
git clone https://github.com/nine19een/CanvasCast.git
cd CanvasCast
npm install
npm run dev
```

在浏览器中打开 Vite 打印的本地地址。仓库没有配置后端服务或 API 密钥；开启摄像头或选择音频输入时，应用才会请求对应的媒体设备访问权限。

### 检查与构建

```bash
# 检查应用 TypeScript 项目
npx tsc --noEmit -p tsconfig.app.json --pretty false

# 运行已配置的 ESLint 检查
npm run lint

# 检查两个 TypeScript 项目并构建应用
npm run build

# 在本地预览构建结果
npm run preview
```

构建将静态资源输出到 `dist`。仓库没有 `test` 脚本或自动化测试套件；代码检查和类型检查是独立的检查项。

本次核验的源码快照在隔离副本中通过了应用类型检查和生产构建；已配置的 lint 检查报告了 **13 个既有错误和 3 个警告**。无窗口浏览器已加载构建后的桌面界面及窄屏提示，但未验证录制、媒体设备或输出编码格式。

## 实现方式

React 和 TypeScript 管理可编辑白板对象及幻灯片状态。编辑器用 SVG 渲染对象；录制流程将演示内容、背景、光标和可选摄像头画面绘制到 canvas，再捕获其媒体流，加入所选麦克风的音轨，交给浏览器 `MediaRecorder` API 生成下载文件。Vite 提供开发服务和生产构建。

录制设置预览与输出共用画布边距、尺寸和摄像头几何布局的计算函数，但这不代表不同浏览器中的输出完全一致。

## 当前限制与后续方向

- **桌面浏览器：**视口宽度低于 900px 时，应用会显示桌面端提示，当前界面不支持在手机上完整编辑与录制。
- **浏览器录制支持：**原项目建议使用较新的 Chrome 或 Edge。`MediaRecorder`、canvas 捕获及 MP4/WebM 编码支持因浏览器而异，不能保证所有环境都导出 MP4。
- **白板按页面会话保存：**当前实现将白板和幻灯片内容放在页面内存中，没有项目保存或导入流程；刷新或关闭页面会丢失这些内容。提词器文字和设置单独保存在浏览器本地存储中。
- **轻量录制：**大型或复杂白板的表现会受设备性能影响，当前没有完整的视频后期剪辑流程。
- **媒体权限：**摄像头和麦克风是否可用取决于浏览器授权与所选设备；重要录制前应先检查声音。

原项目将当前状态描述为 MVP。已有后续计划包括更多导出选项、更高级的图片编辑、更接近压感效果的画笔、更多演示切换效果、大型白板性能优化，以及更好的手机和平板支持。这些是后续方向，尚未给出发布时间。
